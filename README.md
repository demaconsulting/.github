# .github

Organization-wide files for [DEMA Consulting](https://github.com/demaconsulting).

## Contents

- [`profile/README.md`](profile/README.md) - the organization profile shown on the
  [organization page](https://github.com/demaconsulting). Edit it to update the landing page.
- Default community health files (currently `CODE_OF_CONDUCT.md`) are inherited by any
  organization repository that does not define its own. `CONTRIBUTING.md` and `SECURITY.md` are
  project-specific and are maintained in each repository.
